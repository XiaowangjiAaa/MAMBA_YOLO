# 10.21 Scanning 策略的真实影响热力图

## 1. 为什么不再把 Paths 当作主要效果证据

Paths 只表示 token 的排列和连接关系，不能说明该路径对特征产生了多大更新；TP/FP/FN 是最终输出，也无法将变化单独归因到 scanning。普通层特征 RMS 又混合了卷积、CSP 局部分支和扫描分支。

本次新增的可视化直接读取 CPSB 实际加回主分支的残差，不根据路径重新构造响应。对 `SparseCrackPathState`：

\[
Y=X+R_{scan},\qquad
R_{scan}=\gamma M_{path}\odot W_o(\Delta X_{SSM}).
\]

源码仅在显式开启可视化时保存该残差的空间统计，不增加训练参数、不改变 state dict，也不改变模型输出。

## 2. 三类新增图

### Absolute scan update

\[
H_{abs}(i,j)=\sqrt{\frac{1}{C}\sum_cR_{scan}(c,i,j)^2}.
\]

表示扫描分支在该位置产生的绝对更新强度。不同层特征尺度不同，不建议跨 P-level 直接比较绝对数值。

### Relative scan update（主图推荐）

\[
H_{rel}(i,j)=\frac{\operatorname{RMS}(R_{scan}(:,i,j))}{\operatorname{RMS}(X(:,i,j))+10^{-6}}.
\]

表示扫描更新相对于进入 CPSB 的原始特征强度，更适合在同一 P-level 比较 Raster、Cross、Diagonal 与 Adaptive。它是“扫描影响强度”，不是梯度意义上的最终预测因果重要性。

### Memory decay difference

\[
H_{mem}=a^{gated}-a^{without\ gates}.
\]

- 正值：门控让状态保留更多；
- 负值：门控让状态更快遗忘；
- 接近零：memory management 对衰减影响很小。

该图来自同一 checkpoint、同一次前向的内部反事实计算，不是另一个单独训练模型。

## 3. 公平比较规则

论文比较默认使用 Backbone P3/P4。P3 保留细裂缝响应，P4体现更长范围的连续结构；P5 的 20×20 网格过粗，不作为主要图。

对于同一图像、同一 P-level，所有 scanning 方法联合计算第 99 百分位色标，并共享 `vmin/vmax`。不能为每个模型独立 min-max，否则弱响应也会被拉伸成同样明亮。青色轮廓表示 GT，热力图来自预测分支而不是 GT。

脚本同时保存：

- `crack_concentration`：膨胀 GT 带内的平均相对更新除以背景平均更新；
- `top_response_gt_hit_rate`：响应最高的一部分有效特征单元中落入 GT 带的比例；
- `route_strength`、绝对/相对更新均值和 memory delta 均值；
- 原始 NPZ，便于重新排版或采用统一的论文色标。

由于裂缝极细，GT 默认在特征图上膨胀 1 个 cell。膨胀半径和 top-response 比例必须在比较前固定，不能根据某个模型的结果调整。

## 4. 推荐命令

只生成新的 scanning 影响证据，跳过旧的普通 feature/path 八宫格：

```powershell
python visualize_ablation_paper.py --runs-dir output_dir/crack-seg-9.11 --experiments K02 K03 K05 K01 --source "F:\dataset\Public_crack_dataset\SUT-Crack\VOC2012\JPEGImages" --gt-dir "F:\dataset\Public_crack_dataset\SUT-Crack\VOC2012\cnnlabels" --split external --max-images 3 --sample-seed 1 --scan-influence --qualitative-only --scan-influence-roles backbone_P3,backbone_P4 --device 0 --output-dir paper_visualizations/SUT-Crack-scan-influence
```

同时生成最终预测误差图与 scan influence：

```powershell
python visualize_ablation_paper.py --runs-dir output_dir/crack-seg-9.11 --experiments K02 K03 K05 K01 --source "F:\dataset\Public_crack_dataset\SUT-Crack\VOC2012\JPEGImages" --gt-dir "F:\dataset\Public_crack_dataset\SUT-Crack\VOC2012\cnnlabels" --split external --max-images 3 --sample-seed 1 --qualitative-scanning --scan-influence --qualitative-only --device 0 --output-dir paper_visualizations/SUT-Crack-scanning-paper-evidence
```

每次必须使用新的空输出目录。

## 6. 解释边界

相对更新集中在裂缝附近，可以支持“该 scanning 策略将状态传播产生的更新集中于裂缝结构”的表述。但它不能独立证明最终性能提升。论文仍需结合固定协议下的 Mask mAP50、配对逐图指标和成功/失败案例；不能仅选择 Adaptive 热力图更集中的图片。
