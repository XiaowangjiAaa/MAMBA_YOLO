# 8.9 裂缝结构感知 Scan 与 Memory 实验结果及下一阶段计划

本文档记录 `output_dir/crack-seg` 中 B0、S1-S4、M1-M3、C1-C2 的训练结果，并给出下一阶段可直接执行的实验矩阵。原始设计说明见 [`README_CRACK_STRUCTURE_EXPERIMENTS.md`](README_CRACK_STRUCTURE_EXPERIMENTS.md)，本文件以 2026-08-09 的实际训练证据为准。

## 1. 当前结论

当前综合最优模型是 C2：

```text
P3：Orientation-aware H/V Scan
P4：Probability-guided B Write
Loss：guidance 0.05 + orientation 0.02
```

两次 B0 的均值与主要实验结果如下：

| 实验 | Box mAP50-95 | Mask mAP50 | Mask mAP50-95 | Mask AP75 | Fitness |
|---|---:|---:|---:|---:|---:|
| B0 均值 | 0.6360 | 0.6834 | 0.2343 | 0.0946 | 0.9341 |
| S1：P3 Scan | 0.6458 | 0.6988 | **0.2451** | 0.1046 | 0.9539 |
| S2：P3 Scan + 方向监督 | 0.6371 | 0.6860 | 0.2345 | 0.0885 | 0.9347 |
| S3：P4 Scan | 0.6409 | 0.6819 | 0.2313 | 0.0897 | 0.9351 |
| S4：P3+P4 Scan | 0.6264 | 0.6754 | 0.2372 | 0.1018 | 0.9264 |
| M1：P4 Write | **0.6527** | 0.7000 | 0.2373 | 0.0966 | 0.9530 |

| M3：P4 Delta+Write | 0.6442 | 0.6982 | 0.2383 | 0.0970 | 0.9470 |

## 2. 从结果中得到的结构判断

### 2.1 Scan 固定在 P3

S1 有明确收益；S3 没有收益；S4 下降。因此后续主线不再把方向扫描扩散到 P4。P3 同时具备局部几何细节和一定裂缝语义，是更合适的方向传播层。

### 2.2 当前方向辅助监督不能单独成立

S2 明显弱于 S1，说明 Sobel mask boundary 产生的切线标签可能受标注锯齿、裂缝双边界、junction 和下采样混叠影响。需要降低权重并拆分 C2 中两种辅助监督，而不是直接宣称方向监督有效。

### 2.3 M1/C1 的无监督 guidance 接近常数

checkpoint 参数显示，M1/C1 的 guidance 卷积权重仍接近零，而 beta 学成正值。因此其增益可能主要来自近似常数的 B scaling，尚不能证明空间 crack-aware gate 有效。

C2 的 guidance 权重 RMS 已达到约 `0.152-0.156`，明显脱离初始化，说明有监督 C2 确实学习了内容相关概率图。C2 三个 P4 block 的实际 beta 约为：

```text
[-0.0805, -0.0307, +0.0829]
```

前两个 block 抑制、最后一个 block 增强，提示不同深度的 memory role 不同。下一阶段应验证“仅最后一个 P4 block 门控”。

### 2.4 暂停继续强化 Delta

M3 的 Delta alpha 已由初始约 `0.05` 增长到约 `0.105`，但性能仍低于 C2。现阶段应优先改进 B/write 的空间可解释性，暂不增加更强 Delta modulation。

## 3. 新增代码假设

### 3.1 Centered Crack Write

旧版：

```text
B' = B * (1 + beta * g)
```

当 `g≈0.5` 为常数时，旧版仍会退化成全局 B scaling。新版改为：

```text
s  = 2g - 1
B' = B * (1 + beta * s)
```

这样 `g=0.5` 时严格等价于 baseline；背景与裂缝分别对应负、正调制，更能验证性能是否来自空间 guidance。Centered 版本使用 `beta=0.05` 初始化，但由于初始 `g=0.5`，初始输出仍与 baseline 等价，同时 task loss 可以立即训练 guidance。

### 3.2 Last-P4 Write

新增 stage 只将 P4 重复 VSS 中最后一个 block 替换为 crack write，其余 block 完全保持原版。内部采用 `nn.Sequential`，参数路径与原始重复 P4 stage 对齐，便于继承已有权重。

## 5. 推荐训练顺序

自动化入口已经同步更新：`batch_train.py` 默认选择 E00-E10，支持 `--phase A/B/C` 和一次输入多个 `--seeds`；`check_yaml.py --aug9` 检查全部新配置；完整命令见 [`../commands/train_commands.txt`](../commands/train_commands.txt)。批量输出默认写入 `output_dir/crack-seg-8.9`，避免覆盖已有结果。

### Phase A：重复性

使用 00、01、02，分别运行 `seed=1`、`seed=2`。连同已有 seed=0，报告三次均值和标准差。

### Phase B：拆解 C2

使用相同 seed 训练 03、04、05、06。06 必须设置足够大的 patience 或关闭 early stopping，训练完整 300 epoch，排除 C2 只是训练时间更长的可能。

### Phase C：验证新的 memory 解释

训练 07-10。优先级为：

```text
10 > 09 > 08 > 07
```

如果 10 优于 09，说明 centered spatial modulation 有效；如果 10 优于 08，说明只在语义最成熟的最后 P4 block 门控更合理。

仅当某个新版本超过 C2 后，再补 seed=1、2。暂时不训练 P4 Scan、P3+P4 Scan 和更强 Delta。

## 6. 训练与选择 checkpoint 的注意事项

当前 best.pt 的 fitness 同时累加 Box 与 Mask fitness。裂缝分割论文还应保存周期 checkpoint，例如 `save_period=10`，再按 Mask mAP50-95、Mask AP75 和 clDice 离线选择，避免 Box 指标主导 best epoch。

下一轮至少记录：Mask mAP50、mAP50-95、AP75、Recall、clDice、FPS，以及 guidance 的 crack/background 均值差、PR-AUC、方向权重熵和切线误差。

## 7. 当前论文主线

现阶段最可靠的表述是：

```text
P3 决定裂缝结构沿哪个方向传播
             ↓
P4 最后阶段决定哪些语义信息写入 state
             ↓
Centered guidance 排除常数门控带来的伪增益
```

只有 centered/last-P4 消融和多 seed 结果成立后，才能把“crack-aware memory management”作为确定贡献。
