# 8.26 Efficient YOLO11 Crack-Aligned State Propagation

## 1. 研究基线重新定义

8.26 起，主线模型明确以真正的 YOLO11-Seg 拓扑为基线，而不是以 Mamba-YOLO 为基线。当前仓库原有的 `*-yolo11.yaml` 仍然使用 `SimpleStem + VisionClueMerge + VSSBlock`，只是增加 C2PSA 与 v11 风格 Head，因此只能作为历史 Mamba-YOLO 实验。

新的 W00–W07 保留 YOLO11 的两层 stride-2 Conv Stem、Backbone/Neck C3k2 布局、SPPF、C2PSA、PAN/FPN 和 v11Segment。当前旧版 Ultralytics fork 缺少 C3k/C3k2，因此 8.26 将官方兼容实现 backport 到 `block.py`。W00 是后续全部实验必须使用的公平基线。

## 2. 单一核心问题

规则 Raster Scan 的序列邻接与裂缝几何邻接不一致，背景 token 和方向不连续位置的状态会进入裂缝位置。8.24 只在扫描结束后加权 H/V 响应，不能阻止递归状态中的污染。

8.26 不再把 Scan 与 Memory 写成两个平行模块，而是提出 Efficient Crack-Aligned State Propagation（CASP）：Scan 决定状态从哪个邻居到来，Memory 决定该状态能否继续传播，二者由同一个 crack-edge confidence 联合控制。

## 3. AdaptiveC3k2CASP

```text
Input
  └─ C3k2-compatible CSP split/fusion
       ├─ Local Bottleneck/C3k：边缘、纹理、局部细节
       └─ Partial-channel CASP residual
            ├─ shared structure head
            ├─ crack-edge construction
            └─ edge-conditioned selective state update
```

输入输出接口与 C3k2 相同，可用于 Backbone 或 Neck。每个 Block 仅在最后一个内部 repeat 使用一次 CASP，其余 repeat 保持局部 YOLO 单元。

同一个 `EfficientCrackAlignedState` core 还提供 `AdaptiveC2fCASP` 外壳，接口对应 YOLOv8 C2f。它用于后续跨 YOLO 迁移实验；8.26 第一轮仍只训练 YOLO11，避免把基线迁移与核心机制验证混在一起。

### 3.1 高效轻量约束

- 仅 `state_ratio=0.25` 的隐藏通道进入 SSM；W06 降为 0.125；
- SSM expansion ratio 从历史 VSS 的 2.0 降为 1.0；
- state dimension 为 8；
- 只计算 H/V 四条正反序列，不增加 diagonal 计算；
- 不加入 VSS 的 LSBlock 与大 MLP；
- 每个 C3k2 只有最后一个 repeat 含状态分支；
- bounded residual route 初值 0.01，训练初期接近局部 YOLO 行为。

路由变小只降低状态分支影响，当前实现仍执行该分支。因此它是通道轻量化与语义自适应，不是硬条件计算跳过。

## 4. Shared Crack Structure Field

对进入 SSM 的部分通道预测：

\[
(p_i,o_i^H,o_i^V)=f_s(x_i),\qquad
a_i^d=\operatorname{softmax}_d(\tau o_i^d)
\]

`p` 是 crack probability，`o^H/o^V` 是 H/V scan-family logits，三个通道来自同一个零初始化 1×1 structure head。第一轮关闭结构辅助损失，先检验机制本身；只有 W01/W06 稳定优于 W00 后，再加入 GT mask/skeleton 弱监督。

## 5. Crack-Aligned Edge Confidence

对位置与 H/V 方向使用左右或上下邻居的对称平均：

\[
e_i^d=\sqrt{p_i p_{\mathcal N_d(i)}}
       \sqrt{a_i^d a_{\mathcal N_d(i)}^d}
\]

同一条边要求当前点、邻接点都像裂缝，且都支持同一传播方向。

这不是硬动态曲线排序。模型仍计算固定 H/V 候选序列，但无关边在状态更新内部被加速遗忘并降低写入。准确 Claim 是 `crack-aligned gated state propagation`，不是 `exact scan along predicted curved trajectories`。

## 6. 同一 Edge 联合控制 Scan 与 Memory

### 6.1 State retention

\[
\hat\Delta_i^d=\Delta_i^d+\alpha(1-e_i^d)
\]

低 edge confidence 增大 pre-softplus delta，使负 A 对历史状态产生更强衰减；高 confidence 保留更长的同结构历史。

### 6.2 State writing

\[
\hat B_i^d=B_i^d[1+\beta(2e_i^d-1)]
\]

可靠裂缝边增强当前输入写入，不可靠背景边降低写入。

### 6.3 Directional fusion

\[
\omega_i^d=2e_i^d/(e_i^H+e_i^V+\epsilon),\qquad
y_i=\sum_d[1+\gamma(\omega_i^d-1)]y_i^d
\]

同一个 `e` 控制 Δ、B 和方向响应融合：

```text
shared structure field
→ crack-connected directional edge
→ state retention + state writing
→ directional state fusion
```

## 7. 全阶段可用与自适应退化

模块允许替换所有 C3k2。空间/样本路由由 `0.5+p_i` 调整，层级路由由每个 Block 独立的 bounded scalar 控制。浅层方向不可靠时可主要依赖 Local Path，P3/P4 可增强结构传播，Neck 也能根据融合特征调整作用强度。

能够全阶段使用不等于全阶段一定最优。W02/W03 验证部署范围，W01/W06 验证性能—效率平衡。

## 8. 第一轮不提出新 Merge

VisionClueMerge 本质是 2×2 space-to-depth 加 1×1 Conv，用于 VSS stage 下采样；YOLO11 已有 stride-2 Conv。第一轮保留原下采样，避免同时修改 Downsample 与 State Propagation。

只有核心 Block 有效且可视化证明 stride-2 Conv 破坏细裂缝后，才考虑使用同一结构场设计 Crack-Structure-Preserving Downsample。它必须是同一故事的跨尺度延伸，不能成为独立堆叠模块。

## 10. 严格训练顺序

1. W00、W01、W06 使用 seed0；
2. 如果 W01/W06 在 Mask mAP50-95、AP75、clDice 或效率 trade-off 上成立，训练胜者 seed1/2；
3. 再训练 W04/W05/W07，完成统一公式因果消融；
4. 最后训练 W02/W03，验证广泛部署；
5. 本轮不加入新 Stem、Merge、方向辅助损失、拓扑损失或新优化器。

主评价：Mask mAP50-95、AP75、clDice、mIoU、Recall、Params、GFLOPs、FPS。Mask mAP50 只作为宽松指标。

训练后使用 `visualize_model_features.py` 检查 P3/P4 的 crack probability、H/V family probability 和 H/V crack-edge confidence。只有 edge map 确实覆盖裂缝连续边且抑制背景时，才能把性能变化解释为结构对齐传播；仅凭最终 mAP 不能证明内部方向语义。
