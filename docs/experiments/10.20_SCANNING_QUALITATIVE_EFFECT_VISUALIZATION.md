# 10.20 Scanning 策略影响的定性可视化

## 1. 要回答的问题

路径图回答“模块实际如何排列 token”，但不能单独证明这种排列改善了分割。论文还需要回答：在相同图像、GT、阈值和局部区域下，Raster、Cross、Diagonal 与 Adaptive scan 分别造成了哪些漏检、误检及连通性变化。

因此新增的是 **effect visualization**，不是另一张 path visualization。二者证据角色不同：

- 路径图：验证内部机制是否按设计运行；
- 定性误差图：展示不同扫描策略对最终预测的可观察影响；
- 数据集 Mask mAP50：判断总体性能，不能由少数定性样例替代。

## 2. 图的布局与颜色

每行固定同一张图和同一个 ROI，各列为：

`Input | Ground truth | Raster | Cross | Diagonal | Adaptive`

每格上方显示全图与蓝色虚线 ROI，下方显示相同 ROI 的局部放大。预测列使用黑色背景：

- 青色：Correct / TP，`prediction ∩ GT`；
- 珊瑚红：Missed / FN，`GT - prediction`；
- 紫色：Extra / FP，`prediction - GT`。

各模型下方显示该图的 union IoU、clDice，以及相对 Raster 的 IoU 差值。该指标是逐图 class-agnostic union 指标，不是 instance AP，也不替代验证集 Mask mAP50。

## 3. 公平选择样例和 ROI

快速检查可以让脚本以固定 `sample-seed` 抽样，并只根据 GT 前景位置自动生成 ROI。正式论文推荐人工预先固定三类案例，例如弯曲、分叉和低对比度裂缝，并写入 JSON。选择图像和 ROI 时只能看输入与 GT，不能根据 Adaptive 是否获益来挑图。

JSON 格式见 `docs/commands/scanning_qualitative_cases.example.json`。`roi` 是归一化的 `[x1, y1, x2, y2]`。只要提供该 JSON，脚本将严格按 JSON 的顺序和图片执行，`--max-images` 不再参与抽样。

## 4. 推荐命令

自动抽取三张图快速查看：

```powershell
python visualize_ablation_paper.py --runs-dir output_dir/crack-seg-9.11 --experiments K02 K03 K05 K01 --source "F:\dataset\Public_crack_dataset\SUT-Crack\VOC2012\JPEGImages" --gt-dir "F:\dataset\Public_crack_dataset\SUT-Crack\VOC2012\cnnlabels" --split external --max-images 3 --sample-seed 1 --qualitative-scanning --qualitative-only --qualitative-roi-size 0.28 --device 0 --output-dir paper_visualizations/SUT-Crack-scanning-effect-auto
```

正式论文图：先复制并修改案例 JSON 中的文件名和 ROI，再执行：

```powershell
python visualize_ablation_paper.py --runs-dir output_dir/crack-seg-9.11 --experiments K02 K03 K05 K01 --source "F:\dataset\Public_crack_dataset\SUT-Crack\VOC2012\JPEGImages" --gt-dir "F:\dataset\Public_crack_dataset\SUT-Crack\VOC2012\cnnlabels" --split external --qualitative-scanning --qualitative-only --qualitative-cases docs/commands/scanning_qualitative_cases.example.json --device 0 --output-dir paper_visualizations/SUT-Crack-scanning-effect-paper
```

每次使用新的空输出目录。核心成品位于：

- `comparisons/external/scanning/scanning_qualitative_effect.png`
- `comparisons/external/scanning/scanning_qualitative_effect.pdf`
- `comparisons/external/scanning/scanning_qualitative_cases.csv`

同时每个模型/图片目录保存 `<模型名>_pred_union.png`、`gt_union.png` 和 `<模型名>_error_mask.png`，便于后续单独排版与复核。`--qualitative-only` 仅关闭 feature heatmap 和真实路径导出，不改变模型前向、预测阈值或结果。

## 5. 论文解释边界

如果 Adaptive 的局部图显示更少的红色断点，可以表述为该样例中裂缝连续性更好；如果紫色减少，可以表述为背景误检更少。但只有当数据集 Mask mAP50 和配对统计也支持时，才能进一步声称总体提升。当前已有扫描消融的整体数值非常接近，定性图应同时保留成功和失败案例，不能只展示 Adaptive 占优的样例。
